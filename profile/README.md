# Welcome

## Overview

Our mission is to transform the way macOS virtual machines are managed by harnessing the power of proven, open source DevOps infrastructure. We're building an ecosystem that streamlines the deployment, management, and scaling of macOS VMs for both on-premise corporate environments and personal projects. All our projects are free to use and fully open source.

> **Note:** We're still a work in progress-so while our core ideas are taking shape, comprehensive educational content and detailed documentation are not yet available!
